# Research Protocol

Lifecycle:
QUESTION → FRAME → SOURCE → EXTRACT → CLASSIFY → CROSS-CHECK → FINDING → SYNTHESIZE → DECIDE → LINK → REVIEW

Record research ID, question, decision impact, scope/non-scope, sources and retrieval date, source class, exact claim/observation, limitations, contradictions, applicable platform/device/workload, and resulting finding/decision.

Source classes:
- A: project primary artifacts — raw runs, commits, CI logs, artifacts, incidents.
- B: authoritative documentation/standards.
- C: peer-reviewed or consensus research.
- D: secondary technical material.
- E: AI output, snippets, chat, README claims.

Class E is a discovery lead, not sufficient evidence for material claims by itself.

Prioritize primary sources. Separate source fact, project observation, interpretation, hypothesis, and recommendation. If evidence is insufficient, record insufficient_evidence.
High-impact claims should have a second independent source or direct project test unless one authoritative primary source directly establishes the narrow fact.
Never broaden a finding beyond its tested/documented scope.
