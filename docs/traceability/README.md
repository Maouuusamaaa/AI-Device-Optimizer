# Traceability

Governed work should connect:

Requirement → Task → Finding/Evidence → Decision/ADR → Implementation → Test/Experiment → Validation → Release/Artifact

Stable IDs:
REQ-####, TASK-####, FIND-####, EXP-####, ADR-####, RISK-####, INC-####, REL-####, HANDOFF-####

IDs are stable once published. Records are superseded rather than silently rewritten.
