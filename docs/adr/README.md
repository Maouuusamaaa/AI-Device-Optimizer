# Architecture Decision Records

Use an ADR for C3 architecture, Safety Gate/action authority, permission/privacy boundary, cloud/data boundary, methodology/measurement policy, CI trust, signing/release policy, or another hard-to-reverse decision.

Lifecycle: PROPOSED → ACCEPTED | REJECTED → SUPERSEDED | DEPRECATED

Minimum fields: ID, title, status, context, decision, alternatives, evidence links, risks, rollback/exit strategy, owner/reviewer, supersedes/superseded_by.
