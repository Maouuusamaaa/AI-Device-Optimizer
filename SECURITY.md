# Security

Security-sensitive changes are C3 or C4 under PROJECT_RULES.md.

Do not publish credentials, exploit details, private user data, or secrets in issues, PRs, CI logs, or repository artifacts. Use the repository's configured private security reporting mechanism when available.

Security review covers permissions, exported components, IPC, cloud/data boundaries, CI workflows, dependencies, signing, and release provenance. A scan is evidence for its check, not a complete security assessment.
